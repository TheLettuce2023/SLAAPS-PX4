\sect{1. \texttt{SLA\_CFG\_KIND}: which profile is applied}
\begin{tabular}{@{}c p{1.7cm} p{3.0cm}@{}}
\toprule
\textbf{Value} & \textbf{Scope} & \textbf{Use it for}\\
\midrule
\p{0} & Servo bench & Canard commissioning with \p{SLA_BENCH_CH} 0--4. Needs \p{COM_PREARM_MODE} so the vehicle is prearmed. EDF inhibited.\\
\p{1} & Stabilized manual & \textbf{SLAAPS Manual} (restrained or tunnel). Needs power, one estimator, flight data record.\\
\p{2} & EDF commissioning & Armed EDF Bench, \p{SLA_BENCH_CH} 5. Needs \p{SLA_EDF_BMAX} above 0 and valid power.\\
\bottomrule
\end{tabular}

\vspace{3pt}
\textbf{Apply procedure} (every scope change, every parameter file load, every image flash):
\begin{enumerate}[label=\arabic*.]
\item Disarmed, and \emph{outside} the SLAAPS modes (select a stock mode).
\item \p{param set SLA_CFG_KIND <0|1|2>}
\item \p{param set SLA_CFG_APPLY <new value>}. The value must \emph{change}: setting the same number does nothing.
\item \p{slaaps status}: look for \p{configuration valid=1 use=N fault=0}.
\item Reselect the SLAAPS mode.
\end{enumerate}
If \p{valid=0}: read \p{fault=} (section 6) and the line \p{configuration rejected parameter=<name>}.

\textbf{Rules}
\begin{itemize}
\item Any edit to a SLAAPS parameter after an apply invalidates the accepted profile until the next apply.
\item Loading the parameter file resets every value in it, including the canard trims \p{SLA_C1_ZERO}..\p{SLA_C4_ZERO} (file value 0): re-enter them.
\item An entry rejection latches. Leave the SLAAPS mode and reselect it.
\item \warn{Reboot after a servo or EDF Bench session before selecting Manual.} On 2026-11-18 Manual entry was rejected at the worker's first cycle (mask \p{0x900000d5}) after a Bench session until the board was rebooted.
\item \p{SLA_BENCH_EN} is never restored at boot. Saved 1 reads back as 0.
\item The profile apply checks values only. Calibration, qualification and flight acceptance are separate.
\end{itemize}

\begin{tabular}{@{}c p{2.15cm} p{3.4cm}@{}}
\toprule
\textbf{N} & \textbf{State} & \textbf{What it needs}\\
\midrule

\textbf{Operator window:} \p{SLA_MAN_WAIT} 30 s from selection. If states 1--8 are not reached in time the entry is rejected (9).

\sect{9. Hardware map}
\begin{itemize}
\item MAIN 1--4: canards (servo 1 top right, then clockwise), PWM 333 Hz, 1333/1500/1667 \textmu s.
\item AUX 5: EDF, DShot600. AUX 1--4, 6--8 and the ninth FMU output unused.
\item CAN1: pitot (node 125). CAN2: PM08-CAN (node 124).
\item POWER1: I\textsuperscript{2}C digital modules only. A DroneCAN module there disturbs the bus.
\item Compass: external IST8310 on I\textsuperscript{2}C bus 1 (address 0x0E). Internal BMM150 on bus 4.
\item Armed Manual holds the EDF at DShot idle (109) at zero throttle.
\end{itemize}
