CODEX EXECUTION PROMPTS FOR THE CUSTOM RESEARCH VEHICLE
Prepared 2026-09-16

PURPOSE

This file converts docs/CUSTOM_VEHICLE_SITL_ROADMAP.txt into direct prompts.
Use gpt-6-astra as the master agent. Use lower-cost agents for bounded research,
implementation, test, and review work. The master owns architecture, phase gates,
integration decisions, conflicting findings, and the final report to the user.

The prompts deliberately separate work by file ownership. All agents share the
same filesystem, so two agents must never edit the same files concurrently.
Existing uncommitted work belongs to the user and must be preserved.


MODEL ROUTING

- gpt-6-astra, high or xhigh: master orchestration, architectural decisions,
  control-design synthesis, phase-gate decisions, conflict resolution, and
  final review.
- gpt-5.6-sol, high: requirements analysis, physics/control design review,
  evidence assessment, and independent code review.
- gpt-5.6-terra, high: repository tracing, C/C++ or Python implementation,
  Gazebo/PX4 integration, test infrastructure, and companion software.
- gpt-5.6-luna, medium or high: inventory, status collection, documentation
  scaffolding, deterministic data extraction, and narrow mechanical changes.

For lower-model agents, use fork_turns="none" and include all necessary context
in the task message. This enables a model override and avoids copying the full
conversation. Permit no more than three workers at once. Tell workers not to
spawn more agents unless the master explicitly delegates that authority.
